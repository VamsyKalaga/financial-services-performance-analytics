# Customer Segmentation Analysis

## Objective

Analyze customer activity and transaction behavior to identify differences in engagement and customer value.

## Customer Activity Segments

The analysis categorizes customers into:

- Inactive
- Low Activity
- Medium Activity
- High Activity

## Key Metrics

The analysis evaluates:

- Customer count
- Transaction frequency
- Transaction value
- Average transaction value
- Customer activity
- Revenue contribution

## RFM Analysis

RFM analysis evaluates customers based on:

- Recency
- Frequency
- Monetary value

## RFM Segments

The project uses the following analytical segments:

- High Value Active
- Active Customers
- At Risk
- Low Engagement
- Developing

## Business Questions

1. Which customer segments generate the highest transaction value?
2. Which segments have the highest transaction frequency?
3. How many customers are inactive?
4. Which customers show signs of declining engagement?
5. Which segments contribute the largest share of transaction value?
